<objective>
Fix the AI chat path hallucinating the current date. `SYSTEM_PROMPT` in `landing-page/lib/chat-ai.ts` never tells the model what day it is, so relative questions ("tomorrow") get answered from training-data guesses — a user asking in August 2026 was told "tomorrow, August 23, 2023".

Purpose: the keyword/mock fallback in `chat.ts` already resolves dates correctly via `salonTodayIso()`; the AI path — the primary path when `HF_TOKEN` is set — does not. Same widget, two different notions of "today", one of them fabricated.

Output: `SYSTEM_PROMPT` becomes a small per-request `buildSystemPrompt()` that embeds the salon-local (Asia/Yangon) calendar date and instructs the model to resolve all relative dates from it, plus one runnable self-check proving the date string is correct in the salon's zone across the UTC day boundary.
</objective>
